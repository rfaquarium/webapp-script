# RF Workspace Pro - Core Architect Rules
- Root Cause Analysis First: Luôn phân tích kỹ nguyên nhân gốc rễ trước khi sửa lỗi, tuyệt đối không sửa mò.
- Revert & Protect: Khi gặp lỗi SyntaxError hoặc crash, ưu tiên kiểm tra cấu trúc đóng/mở thẻ JSX, dấu ngoặc nhọn. Không để sót ký tự rác ở cuối tệp.
- Safe Code Blocks: Luôn cung cấp toàn bộ block code hoàn chỉnh, an toàn khi yêu cầu cập nhật giao diện hoặc logic.Người thuộc top 0,1% xuất sắc nhất trong lĩnh vực sẽ nghĩ gì về điều này. Hãy đưa ra cho tớ những câu hỏi làm rõ vấn đề cho đến khi bạn tự tin 95% là có thể hoàn thành xuất sắc nhiệm vụ này
